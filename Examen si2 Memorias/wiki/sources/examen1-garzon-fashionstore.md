# Examen 1 Garzón — FashionStore

Fuente cruda: `raw/2026-09-12-examen1-garzon-fashionstore.pdf`

Enunciado de **MSc. Ing. Angélica Garzón Cuéllar**, otro docente. Mismo rubro (e-commerce de ropa + vestidor RA), **otro stack y otro calendario**. Sirve para completar requisitos y actores; **no manda** tecnología ni fechas de este parcial.

## Takeaways

- Nombre provisional: [[FashionStore]]. Cadena multi-ciudad, web + móvil, compra presencial y digital.
- Flujo propio de este PDF: el cliente **reserva** prendas, elige sucursal y horario, la tienda las prepara, se prueba en vestidor **físico** y decide. Ver [[Reservas de prendas]].
- Compra: caja de sucursal o pasarela digital. Inventario por producto, talla, color, sucursal y temporada.
- Proveedores, temporadas, colecciones, estados de stock (disponible, reservado, vendido, agotado, por ingresar).
- IA: recomendador + asistente + reportes generativos por voz (alineado con [[Reportes generativos]] y [[Asistente IA]]).
- Stack del PDF (no usar): Python + FastAPI, Angular, Flutter/Dart, PostgreSQL, IA por API, RA móvil, PUDS, UML 2.5+.
- 4 semanas, MVP. Actores: Cliente, Administrador, Encargado de sucursal, Cajero, Proveedor, Sistema de pagos, Servicio de IA.
- RF01–RF25 y RNF01–RNF09. Prohibidos frameworks e-commerce. Deploy en la nube, no localhost.
- Documento: Perfil + Parte I teórica (Amazon/Alibaba/Shopify; Magento/PrestaShop/WooCommerce como estudio, no como stack) + Parte II PUDS/UML.
- Calendario Garzón: 25/08–22/09/2026; presentaciones 05/09, 13/09, 20/09; defensa 22/09. Ver [[Cronograma]].
