## Takeaways (parcial 23 sep)

- **Stack del parcial:** NestJS + TypeScript, React, React Native, PostgreSQL, deploy Azure. SQL Azure opcional. Python/FastAPI reservado a microservicios. Spring/Angular/Flutter = otro contexto, no este parcial.
- **Informe en 3 partes:** (1) Fundamentación teórica (RA, Nest, React, etc.); (2) Proceso de desarrollo **100% PUD** (Proceso Unificado); (3) mecanismo para que el usuario **aprenda a usar** la app.
- **PUD = metodología** (libro Booch, Rumbaugh, Jacobson). Scrum = framework; para el semestre hay acuerdo aparte.
- **Gráfico que dibujó:** ejes **fases** (inicio, elaboración, construcción, transición) × **disciplinas** (requisitos, análisis, diseño, implementación, pruebas). Las disciplinas **se repiten en cada ciclo**.
- Analogía oral: en PUD, en vez de sprint → **ciclo** (ciclo 1, 2, 3) → versión operativa / incremento.
- **MVP:** lo esencial usable, no lo más fácil.
