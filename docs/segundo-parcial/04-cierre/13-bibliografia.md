# 13. Bibliografía

Cada capítulo de fundamentación (3, 4, 6, 7 y 9) cierra con sus referencias específicas. Aquí se reúnen las obras generales y las del primer ciclo.

## 13.1 Metodología

- Rosenberg, D. y Stephens, M. (2007). *Use Case Driven Object Modeling with UML: Theory and Practice*. Apress.
- Rosenberg, D., Stephens, M. y Collins-Cope, M. (2005). *Agile Development with ICONIX Process*. Apress.
- Stephens, M. y Rosenberg, D. (2010). *Design Driven Testing: Test Smarter, Not Harder*. Apress.
- Jacobson, I., Booch, G. y Rumbaugh, J. (1999). *El proceso unificado de desarrollo de software*. Addison-Wesley.
- Sparx Systems. *Enterprise Architect User Guide: ICONIX*. https://www.sparxsystems.com/enterprise_architect_user_guide/

## 13.2 SaaS y multi-tenencia

- Mell, P. y Grance, T. (2011). *The NIST Definition of Cloud Computing* (SP 800-145). NIST.
- Microsoft. *Architect multitenant solutions on Azure*. Azure Architecture Center. https://learn.microsoft.com/azure/architecture/guide/multitenant/overview
- Amazon Web Services. *SaaS Lens, AWS Well-Architected Framework*. https://docs.aws.amazon.com/wellarchitected/latest/saas-lens/
- Skok, D. *SaaS Metrics 2.0*. https://www.forentrepreneurs.com/saas-metrics-2/

## 13.3 Sistemas distribuidos y operación sin conexión
